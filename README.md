Task 2 – Exploratory Data Analysis (EDA)

Aim:
To understand the dataset using Exploratory Data Analysis techniques and identify patterns, trends, and data issues.

Dataset Used:
- `quotes_dataset.csv`
- If the file is not available, the program automatically creates a sample dataset.

Tools Used:
- Python
- Pandas
- Matplotlib
- OS module

 Steps Performed:

 1. Ask Meaningful Questions
- How many quotes are in the dataset?
- Which author has the most quotes?
- Are there any missing or duplicate values?

 2. Explore Data Structure
- Checked number of rows and columns
- Verified data types using `info()`
- Viewed first few records using `head()`

 3. Identify Patterns and Trends
- Counted number of quotes per author
- Identified authors with higher contributions

 4. Test Hypotheses Using Visualization
- Hypothesis: Some authors have more quotes than others
- Created a bar chart to visualize quotes per author

 5. Detect Data Issues
- Checked for missing values
- Checked for duplicate records

 Output:
- Console output showing dataset details
- Bar chart showing number of quotes per author
- Clean dataset with no missing or duplicate values
